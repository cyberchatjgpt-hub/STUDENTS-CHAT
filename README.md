# Study Squad 📚

A fun demo app where students team up in squads and turn studying into a group game.

## Features
- Squad home with live member status and nudges
- Focus timer (25 min, or 10-second demo mode)
- Points, weekly challenge, confetti
- School leaderboard
- Squad chat with reactions
- Badges and profile

## Run it
Open `index.html` in any browser. No install needed.

## Host it free with GitHub Pages
1. Upload `index.html` and `README.md` to a new repository
2. Go to Settings > Pages
3. Under Source, choose "Deploy from a branch", pick `main` and `/ (root)`, then Save
4. Your app will be live at `https://YOUR-USERNAME.github.io/REPO-NAME/`
